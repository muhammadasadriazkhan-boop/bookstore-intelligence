A Python scraper that turns the competitor website [books.toscrape.com](https://books.toscrape.com/) (a sandbox site built for scraping practice) into a clean business dataset, then uses that data to decide what a new online bookstore should sell.

> *The webpage is not the dataset. The scraper turns it into one.*

---

## How it works

1. **Request** — `requests.get()` downloads a catalogue page's HTML.
2. **Parse** — `BeautifulSoup` finds every `<article class="product_pod">` (one per book) and pulls out the title, price, star rating, stock status and product link.
3. **Clean** — `£51.77` becomes `51.77` (float); the rating word in the CSS class (`star-rating Three`) is mapped to a number 1–5.
4. **Loop** — one reusable `scrape_page()` function is called inside a `while` loop that follows the site's **next** button, so the same code scrapes 3, 5 or all 50 pages.
5. **Analyse** — Pandas answers the business questions; a dynamic-programming (0/1 knapsack) solver picks the best £100 basket.
6. **Output** — `competitor_books.csv`, `rating_counts.png` and `analysis_results.md` are all generated by the code (nothing typed in by hand).

## Mission 1 — Reconnaissance

| Data needed | HTML tag / class found | Notes |
|---|---|---|
| Book card | `<article class="product_pod">` | One per book, 20 per page |
| Book Title | `<h3><a title="...">` | Use the `title` attribute — the visible text is cut off with "..." |
| Price | `<p class="price_color">` | Text like `£51.77`; strip the £ and convert to float |
| Rating | `<p class="star-rating Three">` | Rating is a **word in the class name**, mapped One→1 … Five→5 |
| Availability | `<p class="instock availability">` | Text "In stock" with surrounding whitespace, so `.strip()` it |
| Product URL | `<h3><a href="...">` | Relative link, joined to the page URL with `urljoin` |
| Next page | `<li class="next"><a href="page-2.html">` | Missing on the last page, so the loop stops by itself |

## Final Challenge — The CEO has £100

Solved as a **0/1 knapsack** problem (each book bought at most once, maximise total stars, cost ≤ £100). Prices are converted to pence so the dynamic-programming solution is exact; the result was cross-checked with a second independent method.

| # | Title | Price | Stars |
|---|---|---|---|
| 1 | Sophie's World | £15.94 | 5 |
| 2 | Thirst | £17.27 | 5 |
| 3 | Set Me Free | £17.46 | 5 |
| 4 | The Four Agreements | £17.66 | 5 |
| 5 | Untitled Collection: Sabbath Poems 2014 | £14.27 | 4 |
| 6 | Starving Hearts (Triangular Trade Trilogy, #1) | £13.99 | 2 |
| | **Total** | **£96.59** | **26** |

6 books, £3.41 left over, **26 total stars**, the highest score possible within £100. The four cheapest 5-star books (20 stars) cost £68.33. The remaining £31.67 buys the cheapest 4★ book plus one more cheap book, which adds 6 more stars.

## Business Recommendation

If launching a competing bookstore, I would prioritise **low-priced, highly rated titles** such as Sophie's World, Thirst, Set Me Free and The Four Agreements. The data shows that quality does not cost more at this competitor: 5-star books average **£32.48**, the lowest of any rating level and below the £35.00 overall average, and **4 of the 14** five-star books cost under £18. Since **100% of the competitor's books are in stock**, we cannot win on availability. We should compete by stocking a strong top-rated, low-price range and promoting it as "top-rated for less".
